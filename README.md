# FAKE-NEWS-DETECTION-SYSTEM
A Machine Learning and NLP based system to analyze and detect fake news using data analytics and visualization.
# 📰 TruthGuard AI - Fake News Detection

A beginner-friendly Fake News Detection project developed using Python and Streamlit.

## Features
🔍Detects Fake or Real News
🎯User-friendly interface
🎯 Built using Python
🎯Streamlit-based web application
